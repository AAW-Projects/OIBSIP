# House Price Prediction using Linear Regression

## 📌 Overview

This project develops a Linear Regression model to predict house prices using the Ames Housing dataset. The project covers data preprocessing, feature engineering, model building, evaluation, and visualization.

---

## 🎯 Objective

- Predict house prices using machine learning.
- Build and evaluate a Linear Regression model.
- Analyze factors influencing house prices.

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Dataset

Ames Housing Dataset

---

## 📊 Workflow

- Data Exploration
- Missing Value Handling
- Data Cleaning
- One-Hot Encoding
- Train-Test Split
- Linear Regression
- Model Evaluation
- Prediction Visualization

---

## 📈 Model Evaluation

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

---


## 📈 Results

- Achieved an R² Score of approximately 0.73.
- Successfully predicted house prices using Linear Regression.
- Identified the most influential features affecting house prices.
