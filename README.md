# 📂 Projects Included

## 📈 Task 1 - Exploratory Data Analysis on Retail Sales

### Objective

Analyze retail sales data to identify sales trends, customer behavior, regional performance, and product insights through data visualization.

### Key Steps

- Imported and explored the dataset
- Checked data types and summary statistics
- Identified missing values and duplicates
- Converted date columns into datetime format
- Extracted Year and Month features
- Performed exploratory data analysis
- Created multiple visualizations
- Generated business insights

### Visualizations

- Monthly Sales Trend
- Customer Segment Analysis
- Sales by Region
- Sales by Category
- Sales by Sub-Category
- Top Selling Products
- Top States by Sales
- Sales Distribution
- Correlation Heatmap

### Key Insights

- Consumer customers generated the highest revenue.
- Technology products recorded the highest sales.
- West region performed better than other regions.
- Sales increased significantly during the final months of the year.
- California contributed the highest overall sales.

- Visualized customer segments
- Analyzed cluster characteristics

- Spending Score

### Visualizations

# 🏠 Task 3 - House Price Prediction using Linear Regression

### Objective

Develop a machine learning model to predict house prices based on various housing characteristics.

### Key Steps

- Loaded the Ames Housing dataset
- Explored dataset structure
- Handled missing values
- Removed columns with excessive missing data
- Filled remaining missing values
- Encoded categorical variables using One-Hot Encoding
- Split data into training and testing sets
- Trained a Linear Regression model
- Evaluated model performance
- Visualized predictions and residuals

### Model Evaluation

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### Visualizations

- Actual vs Predicted House Prices
- Residual Plot
- Top Feature Coefficients

### Key Insights

- The model achieved an R² score of approximately **0.73**.
- Above-ground living area had the strongest influence on house prices.
- The model predicted average-priced houses more accurately than high-priced houses.
- Proper preprocessing significantly improved model performance.
